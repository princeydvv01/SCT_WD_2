# SkillCraft Technology - Task 2

## Stopwatch Web Application

This project is developed as part of the SkillCraft Technology Web Development Internship.

## Features

- Start Stopwatch
- Pause Stopwatch
- Reset Stopwatch
- Record Multiple Lap Times
- Accurate Time Tracking
- Responsive Design
- Clean and User-Friendly Interface

## Technologies Used

- HTML5
- CSS3
- JavaScript


## How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser


## Project Output

The stopwatch application allows users to:

- Start the timer
- Pause the timer
- Resume from paused time
- Reset the stopwatch
- Record unlimited lap times
- View lap history in real time
